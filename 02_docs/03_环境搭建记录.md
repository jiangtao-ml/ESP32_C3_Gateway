## 3. 开发板包 / 工具链排障（M1 的主要障碍）

**现象**：开发板管理器装包下载失败。

**根因与修正**：

- **ESP32-C3 是 RISC-V 芯片 → 工具链是 `esp-rv32`（如 `esp32:esp-rv32@2601`）**，不是 Xtensa 的 `esp-x32`。名字看错会让排障方向跑偏（项目早期记录即误记为 `esp-x32`）。
- 使用 **CN 镜像**：`https://jihulab.com/esp-mirror/espressif/arduino-esp32/raw/gh-pages/package_esp32_index_cn.json`
- 配完镜像**必须完全关闭并重启 Arduino IDE** 才生效；开发板管理器里**必须选带 `-cn` 后缀的版本**。
- **判断镜像是否生效**：看下载 URL 指向 `jihulab.com` 才算生效；仍指向 `github.com` / `20.205.243.166` 则未生效。

**完整四方向排障手册**：`02_docs/11_esp32开发板包排障.md`（v1.2，状态：已解决）。

## 4. 编译选项（M1 定稿，后续里程碑沿用）

| 项 | 设置 |
| --- | --- |
| 开发板 | `ESP32C3 Dev Module` |
| **USB CDC On Boot** | **Enabled** ← 必需，否则 `Serial` 无输出，且 `Serial` 会占 GPIO20/21 与 `Serial1` 冲突 |
| Flash Size | 4MB (32Mb) |
| Upload Speed | 921600（不稳定时降到 115200） |
| CPU Frequency | 160MHz |

编译产物（Codex 2026-10-03 用 `arduino-cli v1.5.1` 复验）：**Flash 997299 B (76%) / RAM 38244 B (11%)**，零错零警告。

## 6. 教训（写入长期记忆）

1. **`esp-rv32` ≠ `esp-x32`** —— ESP32-C3 是 RISC-V。
2. CN 镜像配完**必须重启 IDE** 并选 `-cn` 后缀版本。
3. `USB CDC On Boot = Enabled` 是本项目**硬性要求**（不是可选优化）。
