## 1. 目标与验收标准

| 项 | 内容 |
| --- | --- |
| 目标 | ESP32 连上 WiFi（静态 IP）、完成 SNTP 对时（东八区）、每秒 1 包 UDP 心跳到电脑 NetAssist |
| 验收 | NetAssist 每秒收到一行 `YYYY-MM-DD HH:MM:SS \| HEARTBEAT`；时间正确（+0800）；连续 ≥60 s 不断包；断网可自恢复 |

| 项 | 值 | 说明 |

| ESP32 静态 IP | **192.168.1.200** | `WiFi.config(192.168.1.200, 192.168.1.1, 255.255.255.0, 192.168.1.1)` |
| 网关 / 掩码 | 192.168.1.1 / 255.255.255.0 | |

## 4. 关键修正（本项目重要正确性修正之一）

### 4.1 NTP 时区串不能加尖括号

- ❌ `configTzTime("<CST-8>", "ntp.aliyun.com")` —— POSIX 会把 `<CST-8>` 当成**分区名字面量**，偏移缺省为 0 ⇒ 等效 UTC，**时间差 8 小时**。
- ✅ `configTzTime("CST-8", "ntp.aliyun.com")`。
- 另：**SNTP 必须在 WiFi 连上之后再初始化**；WiFi 断开/重连成功后需**重新触发一次** `configTzTime`。
- 修复提交：`044242c`（任务书 v0.3.2 的 FR-02 亦同步修正）。

### 4.2 收帧策略由「固定超时」改为「帧长驱动 + 三级超时」

- 原设计"固定 300 ms 收帧"在收帧失败时每秒独占 30% 周期，且 9600 下帧间静默不足以判帧尾。
- 改为：**首字节 80 ms → 字符间隔 4 ms（判本帧结束）→ 帧长驱动（收满即止）→ 300 ms 兜底**。
- 该改动是 M4 能跑通的前置条件之一。
