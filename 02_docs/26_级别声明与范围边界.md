## 1. 级别声明

> **本项目目标级别 = L1 实验室样机。**
>
> 含义：**单台装置在实验室/配电箱现场能稳定采集真机数据、结果可复现、故障可定位。**
> 不承诺：批量一致性、环境包络、电气隔离、防护等级、第三方认证。

选择理由（用户 2026-10-22 裁定）：现状硬件不改动（洞洞板直焊、不隔离、不加防护），后续只补外壳。

**级别越高不是越好，是越贵。** L1 是"把这件事做对"，L2 是"把它做成产品"，L3 是"把它做成能过认证的产品"。本项目停在 L1，并在 §5 写清升级到 L2 需要改什么。

## 2. L1 的验收定义（5 条，全部满足才算完成）

| # | 判据 | 判据细节 |
| --- | --- | --- |
| L1-1 | **能采** | 真机连续 168 h，数据行送达率 ≥96%（口径见 `24` §3），四计数器对账闭合 |
| L1-2 | **可信** | 39 字段与 `raw` 自校验一致；`quality` 与字段级 `invalid` 一一对应；`-40℃` 伪装与真越界可区分 |
| L1-3 | **可诊断** | 任何缺口能按 `24` §6 判定树归到某一层；`UNATTRIBUTED ≤0.1%` |
| L1-4 | **可复现** | 报告可由 `--report-only` 逐字节重算；环境、固件 bin、字段字典版本全部留痕 |
| L1-5 | **可交付** | 有一份能给别人看懂的结项文档（`02_docs/25` + `10_验收结项`），含局限与未达标项 |

> 注意：**"跑满 168h"只是 L1-1 的一半**。另外四条才是"实验室样机"和"跑了个脚本"的区别。

## 3. 明确不做（4 项，连同理由一起记）

| # | 不做 | 理由 | 谁决定的 |
| --- | --- | --- | --- |
| N-1 | **485 电气隔离** | 隔离模块 + 隔离电源约 +30–60 元/台，且要改布板；L1 单台在受控现场使用，靠**操作红线**替代（见 §4） | 用户 2026-10-09 裁定"AB 直连" |
| N-2 | **打样 PCB** | 洞洞板已能跑通，L1 不追批量一致性；打样会引入等待与焊接方式变更 | 用户 2026-10-22 裁定"现状不改" |
| N-3 | **EMC / 安规 / 温宽认证** | 需第三方实验室，费用与周期远超项目预算；且认证前置条件是 N-1、N-2 先做 | 用户 2026-10-22 |
| N-4 | **批量一致性与出厂标定** | n=1，没有第二台可比对；L1 不承诺"同批 10 台行为一致" | 同上 |

**这四项不是"忘了做"，是"决定不做"。** 写在这里的目的：将来任何人（导师、评审、客户）问起，答案是一致的，不需要重新辩论一遍。

## 4. 残余风险与补偿措施

不做隔离和防护，风险不会消失，只能**转移到操作约束上**。以下措施是 L1 成立的前提，不是可选建议：

| 风险 | 后果 | 补偿措施（必须执行） |
| --- | --- | --- |
| **无隔离，强电经 USB 共地** | 共模电流经 USB 地回路，**可烧电脑主板** | 🔴 真机带电期间**必须拔掉 USB 数据线**，用独立 5V 电源；每次改接线前**断电 + 验电**；没有万用表不许开箱 |
| **无 TVS / 无共模电感** | 浪涌、静电直接打到 MAX13487 或 ESP32 | 只在**受控室内环境**使用；雷雨天与配电操作期间断开 A/B；不承诺户外与长线（>100 m）场景 |
| **无看门狗** | 固件卡死 → 停止采集，需人工断电 | 接收端 `GAP > 30 s` 告警 + 每日巡检；接受"最长停机到一个巡检周期" |
| **洞洞板直焊、无阻焊** | 焊点疲劳、锡桥、机械强度低 | 焊后电检 M1–M17；线束做应力释放；装壳后不频繁拆装 |
| **裸板无外壳（当前）** | 异物短路、静电、误触 | **尽快装壳**（用户已计划）；装壳前板子只在桌面/箱内使用 |
| **UDP 明文 + AP 常开** | 同网段可嗅探/伪造 | 只在隔离的实验网段用；凭据见 `secrets.h`，不入库不截图 |

> 这六条要与 `PROGRESS.md §7`（硬件安全红线）保持一致；冲突时以红线段为准。

## 5. 将来升级到 L2 的最小改动（备查，现在不做）

| 改动 | 为什么必须 | 影响面 |
| --- | --- | --- |
| 加 485 隔离（ADM2483 类 + 隔离电源） | 工业现场共模电压必然存在 | 布板 + BOM + 成本；固件不变 |
| 打样 PCB 替代洞洞板 | 批量一致性、机械强度、可返修 | 原理图/BOM/装配工艺全套 |
| 加端口防护（TVS + PTC + 共模电感） | 浪涌/静电是现场头号杀手 | 布板 |
| 加看门狗 + 掉电安全 | 无人值守场景不接受人工断电 | 固件（`loopTaskWDT` + NVS 原子写） |
| 做 5–10 台 + 出厂检验规范 | L2 的定义就是"可复制" | 工装 + 流程 + 批次数据 |
| 环境包络实测（高低温） | 客户会问"多少度能用" | 设备/外协 |

> 升级顺序建议：**先隔离与防护（硬件）→ 再 PCB（工艺）→ 最后批量与包络（数据）**。反过来做等于在错的硬件上攒数据。
