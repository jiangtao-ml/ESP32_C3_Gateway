## 1. 目的与范围

把 ESP32-C3 网关从"电脑模拟从站（M4）"推进到**真实 QI 用电采集设备（STB3-125）**，验证：
① 功能码从 `0x03`（回环自测）切到 **`0x04`（读输入寄存器）**；② 3 段读取能拼出完整 39 个寄存器；③ 数据经 UDP 上送到电脑。

**不在本次范围**：JSON 上行（属功能对齐批次 1）、一帧读全 39（E-02，属批次 2）。

## 2. 现场与安全

| 项 | 值 |
| --- | --- |
| 设备 | STB3-125（QI 用电采集，RS-485 / Modbus RTU，**只读**） |
| 现场 | 带电配电箱 `GOOWANT PZ30`（**疑似三相 380V**） |
| 供电隔离 | **充电宝供电 + ESP32 的 USB 数据线已拔**（USB 拔后电脑只看到 COM3/COM4 蓝牙口，无 COM5） |
| 电脑侧 | WLAN `192.168.1.113`；UDP 监听 **8888** |
| ESP32 | 静态 `192.168.1.200`，本地 UDP 端口 `12345` |
| 串口 | 运行期**无串口**（USB 已拔）⇒ 唯一可见通道 = UDP |

## 3. 链路与请求帧

链路：`STB3-125 ──RS-485/Modbus RTU──> ESP32-C3（0x04 轮询 + 打时间戳 + UDP）──UDP 8888──> 电脑`

请求帧（均 8 字节，CRC 已由 `06_tests/m5_frame_check.py` 独立复核）：

| 段 | 覆盖 | 帧 | 期望响应 |
| --- | --- | --- | --- |
| S1 | 30001–30016（0x0000–0x000F，16 个） | `01 04 00 00 00 10 F1 C6` | 37 B |
| S2 | 30017–30032（0x0010–0x001F，16 个） | `01 04 00 10 00 10 F0 03` | 37 B |
| S3 | 30033–30039（0x0020–0x0026，7 个） | `01 04 00 20 00 07 B0 02` | 19 B |

拼接缓冲 = **78 字节 = 39 个寄存器**（S1→偏移 0、S2→32、S3→64）。

## 4. 判据与结果

| 判据 | 结果 |
| --- | --- |
| UDP 在电脑侧真收到包 | ✅ 共 **59 个包**，来源全部 `192.168.1.200:12345` |
| 每包完整 78 字节 / 39 寄存器 | ✅ 全部完整 |
| 读取成功率 | **59/60**（60 s 内少 1 包：20:36:10 与 20:36:12 之间有 **1 秒缺口**，该包未定性） |
| 数据自洽 | ✅ 无锁 / **合闸**、**A 相 222 V**、**49.9 Hz**、**N_temp 24 ℃**、A 相电量高字 4 / 低字 `E5CF` |
| 已知不上报字段处理 | A/B/C_temp 恒 `= -40 ℃`，判为**"型号已知不上报"**（不降级整行） |

**首帧 39 字段判读摘要**（完整表见 `03_logs/M5真机首测_解析_20261005.log`）：

```
reg0  openState 0x00F0 -> 无锁 / 合闸
reg4  frequent  0x01F3 -> 49.9 Hz
reg6  N_temp    0x0040 -> 24 ℃
reg8  A_voltage 0x00DE -> 222 V
reg7  A_temp    0x0000 -> -40 ℃  <<< 无效（接线柱温度传感器缺装，恒量程下限）
reg14 A_H       0x0004 ;  reg15 A_L 0xE5CF -> A 相总电量（公式待定，见 §6）
```
