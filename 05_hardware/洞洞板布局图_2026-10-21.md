### 2.0.1 交叉怎么办（2026-10-23 定）

**结论：锡条上不做交叉。** 6 处交叉全部由「绝缘飞线从锡条上方架空跨过」消解 —— **0 过孔、0 处锡条互压**。

| # | 孔位 | 交叉的两根 | 谁架空 |
| --- | --- | --- | --- |
| X1 | F-004 | W3 GND × W1 5V | W3（绝缘线） |
| X2 | F-013 | W5 TXD × W1 5V | W5（绝缘线） |
| X3 | G-013 | W5 TXD × W2 3.3V | W5（绝缘线） |
| X4 | F-014 | W4 RXD × W1 5V | W4（绝缘线） |
| X5 | G-014 | W4 RXD × W2 3.3V | W4（绝缘线） |
| X6 | P-013 | W4 RXD × W5 TXD | 两根都绝缘 |

三条硬约束（违反任一条即短路）：

1. 🔴 **原方案 W1(5V) 与 W3(GND) 都落在 F-004 同一个孔** —— 那不是"交叉"，是 5V 直碰 GND。改后 **F-004 孔里只焊 W1**，W3 从锡条上方架空过去。
2. **不能靠"穿到背面绕一下"来解决**：本板是**双面镀锡 + 金属化孔**，正面焊过的孔，**背面环也是同一个网**。从背面横穿 F 列 / G 列（W1 / W2 的竖直轨）必然碰到它们的孔 ⇒ 一样短路。要在背面绕，只能走到 **row ≤ 002**（W1 在 F-003 就收头了，F-002 以下才是空的）——可行但绕远，不推荐。
3. **绝缘线上板必须在锡条焊完之后**再穿，且交叉点要把线**拱起来**，不要绷平压在锡条上；漆包线建议在交叉段套 3–5 mm 热缩管。

> 若坚持 8 根全用锡条：W3 可改 `H-004 → G-004 →（背面）G-002 → C-002 →（正面）C-017`，2 个过孔、0 交叉。W4/W5 同法只剩 row 001/002 两条通道，且与 W3 抢线 —— **不划算，直接用 0.3–0.5 mm 漆包线**。


### 图 1 · 元件面 1:1 布局图

目标：确定**每个器件焊在哪几个孔**，以及它们之间的几何关系。

必须画出并标注：

| 元素 | 要求 |
| --- | --- |
| 板外形 | 70 × 90 mm 实线矩形，四角标尺寸 |
| 2.54 点阵 | 每隔 5 mm 画一条淡格线即可（不必每孔都画圆） |
| ESP32 引脚两排 | **行距 15.24 mm（6 格）**，靠右下侧；**USB 口朝板外**，标出 USB 朝向箭头。**模块直接焊在板上，不画排母** |
| 485 逻辑侧 5 脚 | 居中；按丝印顺序标 `GND / TXD / RXD / VCC / EN`（从上到下） |
| 485 总线侧 3 脚 | 相对 5 针排**偏 1 格（居中）**；标 `B / A / GND` |
| 端子 | **3P 5.08 mm**，靠左边缘（出线朝外），三个位标 `1 / 2 / 3` |
| 测试点 | 三个独立焊盘：`TP5V`、`TP33`、`TPGND` |
| 分区 | 用浅色虚线框出"5V 区"与"3.3V 区"，两区之间留 ≥2 孔 |
| 禁装提示 | 红框写：**"禁止加装 120Ω / 4.7k / 电平转换"** |

**关键尺寸核对**（这四项错一个就装不上）：

1. SuperMini **两排引脚**行距 = **15.24 mm**（不是 2.54 的整数倍以外任意值）
2. SuperMini 每排 **8 孔**（不是 14 孔）
3. 模块 5 针排与 3 针排**间距 = 2 格（5.08 mm）**，且 3 针排相对 5 针排**居中偏 1 格**
4. 端子 3P **5.08 mm** 间距 = **正好跨 2 个孔**

### 2.1 外壳预留（**必须在焊之前定，焊完再改就来不及**）

用户已明确后续要装外壳。外壳虽然以后做，但**板子的外形、安装孔、开窗位置必须在画图时就留出来**——焊完再钻孔会把焊点和走线震裂。

| 项 | 要求 | 为什么 |
| --- | --- | --- |
| **安装孔** | 4 × ⌀3.2 mm（配 M3 自攻螺钉），距板边 **≥5 mm**、距最近焊盘 **≥4 mm** | 太靠边会崩边；太近焊盘会钻断走线 |
| **钻孔时机** | **焊之前钻**（或至少在焊大面积铜箔之前） | 手电钻的振动会震裂已完成的焊点 |
| **背面空间** | 板下（焊接面）留 **≥5 mm** 净空 | 洞洞板背面有锡点，贴平装会顶住壳底/支柱，可能短路 |
| **正面净高** | 实测元件最高点（含热缩、排针）后 **+5 mm** 余量 | 买盒子时按这个数选，不要按板子厚度估 |
| **USB-C 开窗** | 记下"板边 → USB 口中心"的距离与高度 | 装壳后要能插线；位置错了要么开窗偏、要么只能拆壳烧录 |
| **端子出线** | 端子朝**壳体出线孔**那一侧，且留 ≥10 mm 走线空间 | 线要能弯出来，不能顶住壳壁 |
| **板外形与盒子** | **先定盒子，再定板外形**（或先定板，再按板选盒），二者必须同时确定 | 70×90 的板塞不进 100×68 的明装盒（90 > 68） |

**建议流程**：先用纸板剪一块 70×90 试装进候选盒子 → 确认 USB 口与端子能对上 → 再在图上定安装孔 → 再钻孔 → 最后焊。

> 这一节不能省。装壳是 L1 的最后一步（见 `02_docs/26` §3），但如果布局没留位置，就会变成"要么不开窗、要么拆板重做"。

### 图 2 · 接线 / 网络图

目标：把 8 根线**按角色**连起来，而不是按丝印同名连。

画法：

- 每个引脚画一个小圆，圆旁标 **"器件.脚名"**，例如 `U1.20(RX)`、`M1.TXD`。
- 每根线起止两端都标 **`W1`…`W8` 编号**，与操作卡 §3 表严格对应。
- 线的**走向**画出（直连 / 绕行 / 从哪两排孔之间穿过），不要只画逻辑连接。
- 每根线旁标注**线色**。

必须写清的三条"角色"注释：

```
W4：ESP32 TX(21) ──► 模块 RXD       （模块 RXD = 芯片 DI，是"收"）
W5：模块 TXD ──► ESP32 RX(20)       （模块 TXD = 芯片 RO，是"发"）
W2：ESP32 3.3 ──► 模块 EN           （固定高电平，不是 5V）
```

> **禁止写"TXD 接 TXD"这种表述**。写角色不写同名，是这张图唯一的目的。

### 图 3 · 焊接面镜像图

目标：检查从背面看是否短路、是否要跨线。

做法：把图 1 放在描图纸下，沿**长边**翻面描一遍；或直接在描图纸上按镜像画。

检查点：

- 镜像后的引脚序号是否仍与实物一致（拿模块对着描图纸插一下最快）
- 同一列相邻两孔之间是否有两条线要跨过（有 ⇒ 改走线或换孔位）
- 焊盘之间的**锡桥风险区**（间距 2.54 mm 的相邻飞线）是否已用不同层/不同方向避开

## 3. 八项自查（前 5 项必做，后 3 项有时间就做）

| # | 检查项 | 通过判据 |
| --- | --- | --- |
| C1 | **端点计数** | 每个网络（除 GND）**恰好 2 个端点**；GND 逐点打勾（应 ≥5 处：J2.2 / J3.1 / J5.3 / TPGND / 模块 GND） |
| C2 | **走线交叉：锡条上必须为 0** | v3 已做到 0 处锡条互压；6 处交叉全部由绝缘线架空跨过（见 §2.0.1）。**出现锡条压锡条 ⇒ 停手改线，不要指望"焊的时候绕一下"**。仍不得从模块体下方穿过 |
| C3 | **电源间距** | 5V 与 GND 不相邻；5V 与 3.3V ≥2 孔（5.08 mm） |

| C5 | **角色朗读** | 沿 W1→W8 逐根念："ESP32 发，模块收" / "模块发，ESP32 收"。**不许念丝印同名**。由第二个人听并核对 |
| C6 | **实物摆位** | 把两个模块真的摆在纸上，看引脚是否落进所画的孔位 |

## 5. 从图到板：落笔即定孔

画完图后，**不要**拿着图直接焊。先做一次"打点"：

1. 把图 1 垫在洞洞板下，用**记号笔**在板上点出第 1 脚与第 8 脚（或 5 脚排的首尾）**两个孔**（不必全点）。
2. 把模块的引脚**干插**进被点的孔里，从背面看是否每根都落孔、板面是否平贴。
3. 全部对上再开始焊第一个脚。
4. ⚠️ **本板无排母，模块是直焊的**：焊上即不可拆。干插定位这一步做不好，后面只能拆焊返修。

这一步花 3 分钟，能避免"焊到第 7 个脚发现整排偏了一格"。
