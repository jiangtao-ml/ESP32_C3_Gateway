## 2. 引脚位置（ESP32-C3 SuperMini）

板面丝印（两排，USB-C 为参照）：

| 排 | 引脚 |
| --- | --- |
| 一侧 | `5V`、`G`、`3.3`、`4`、`3`、`2`、`1`、`0` |
| 另一侧 | `5`、`6`、`7`、`8`、`9`、`10`、`20`、`21` |

- 本项目用：**`5V`、`G`、`20`（UART1 RX）、`21`（UART1 TX）**。
- `GPIO20/21` 在 **USB-C 对侧那一排的末端** —— 接线前先认板面丝印。
- `GPIO18/19`（原生 USB D-/D+）**未引出**，不会与 UART1 抢脚。
- `3.3` 引脚本次**不使用**（MAX13487 需 5V）。

## 3. MAX13487 模块的两排管脚（⚠️ 读了再插）

> **两排脚的性质完全不同，认丝印字母，不要数位置。**

| 排 | 位置 | 丝印（从左到右） |
| --- | --- | --- |
| **逻辑侧（5 脚）** | 一侧 | `GND` / `TXD` / `RXD` / `VCC` / `EN` |
| **总线侧（3 脚）** | 另一侧 | **`B` / `A` / `GND`** ← **`GND` 在最后！** |

⚠️ 旧材料把总线侧记作 `GND / A / B`，**是错的**；据此接线会把 `B` 接到 `GND` 上。
⚠️ 模块**跨在面包板中央凹槽上**，所以两排脚**分居两侧半边**：总线侧在 `f–j`，则逻辑侧必在 `a–e`。

## 4. 接线表（✅ 2026-10-04 M4 实测通过）

### 4.1 逻辑侧（5 脚排）—— ⚠️ 注意 `TXD`/`RXD` 是**交叉**的

| 模块脚 | 接到 ESP32-C3 | 说明 |
| --- | --- | --- |
| `GND` | **`G`** | 必须共地 |
| **`RXD`** | **`21`** | ⚠️ **不是 `TXD`！** 模块 `RXD` 才是芯片的发送**输入**（`DI`） |
| **`TXD`** | **`20`** | ⚠️ **不是 `RXD`！** 模块 `TXD` 是芯片的接收**输出**（`RO`，别名 `RXO`） |
| `VCC` | **`5V`** | 必须 5V |
| `EN` | **`5V`** | **接固定高电平**；不得悬空 / 接 GND / 动态切换 |

> ### ⚠️⚠️ 为什么必须是交叉
> 模块丝印写的是**模块自身的收发方向**，不是"你那边接什么"。
> 按"同名对接"（`21`→`TXD`）会**双向全断**：`21` 顶在芯片输出脚上对撞、芯片 `DI` 从未被驱动 ⇒ 驱动器一点差分都不输出；
> 同时 `20` 挂在 `DI`（高阻输入）上 ⇒ 什么都收不到。**而模块电源灯仍亮**，极易误判为硬件故障。
> **本项即 M4 卡 5 天的真凶**，详见 `02_docs/14_M4排障全过程复盘_2026-10-04.md`。

### 4.2 总线侧（3 脚排）

| 模块脚 | 接到 |
| --- | --- |
| **`A`** | USB 转 485 的 **`A`**（A↔A，**不要交叉**） |
| **`B`** | USB 转 485 的 **`B`** |
| `GND` | 面包板 `GND`（与 ESP32 同一片地） |

### 4.3 供电

```
电脑 USB ──▶ ESP32-C3 SuperMini
                 │  5V 引脚 ──▶ MAX13487 的 VCC（以及 EN）
                 └  G  引脚 ──▶ MAX13487 的 GND ──▶ USB 转 485 的 GND   （星形共地）
```

- ⚠️ 面包板阶段**不使用 HW566**，由电脑 USB 供电。
- 也可把 `VCC` / `EN` 接到 **USB 转 485 模块的 `+5V` 端子**（USB VBUS，独立 5V 源）——本次实测两种供电都可行。
- **`Serial1` 参数**：`Serial1.begin(9600, SERIAL_8N1, 20, 21)`（形参顺序为 `baud, config, RX, TX`）。

### 4.4 分压（可选）

- 2026-10-04 实测：**拆除 1k/2k 分压、`RXO`（= 模块 `TXD` 脚）直连 `GPIO20` 后，M4 仍 100% 通过**
  ⇒ 本模块**可直连**（与老师"不用电阻"一致）。
- ⚠️ 但**未用万用表实测 `RXO` 空闲电平**，电气合规性属 `[待确认]`。若日后换模块或接真机，**先量电平再决定**：
  5V → 必须 `RXO —[1kΩ]— 节点 —[2kΩ]— GND`，节点接 `GPIO20`；3.3V → 直连（加分压会掉到 2.2V < VIH 2.475V）。

## 5. 面包板使用要点（⚠️ 两类隐形断路）

> **同一行的 `a–e` 五个孔内部连通（同一电气节点）；`f–j` 同理；中央凹槽把左右两半隔开。**

| 陷阱 | 说明 | 后果 |
| --- | --- | --- |
| **插到"同一行的另一半边"** | 以为与对面是同一个节点 | **看着接上了，实际断路** |
| **整排错行** | 插到相邻一行 | 同上 |
| **模块未插到底** | PCB 未贴板、引脚座外露 | 引脚虚接（尤其 VCC/GND） |

**排查口诀**：任何一根线，两端都必须落在**同一行、同一半边**（跨线本身没问题，插孔选半边才有问题）。

## 6. ⚠️ 安全红线（务必遵守）

1. **所有 GND 必须共地**（ESP32 / MAX13487 / USB 转 485 / 电源）。**USB 转 485 必须带 GND 端子。**
2. `MAX13487` 接 **5V**、`ESP32-C3` 接 **3.3V**，两者同时上电。
3. `USB CDC On Boot` 必须设为 **Enabled**（否则 `Serial` 占 GPIO20/21 与 `Serial1` 冲突）。
4. **禁止把 5V 直灌 `GPIO20`**（绝对最大额定 3.6V）；`RXO` 电平未实测前不得直连。
5. **STB3-125 控制类命令一律禁止执行**（本阶段只读不写）。
6. **接线 / 改线一律先断电。**
7. **M5 接 220V 真机前必须闭环 R-14**：改用充电宝 / 独立供电，或加 RS485 隔离模块 —— 否则强电经 USB 共地**会烧电脑主板**。
