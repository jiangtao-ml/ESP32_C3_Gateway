> ① 模块按**字母**接不按位置：逻辑侧 `VCC/TXD/RXD/EN/GND`；总线侧 **`B` → `A` → `GND`**；

## 2. 布局建议（横放，元件面朝上）

```
 [充电宝 USB 线]          ┌─────────────── 洞洞板 ───────────────┐
      │                  │                                       │
      ▼                  │  [排母:ESP32-C3]      [排母:MAX13487]  [端子:A B GND]
   ESP32 的 5V/G          │   (靠右边缘,USB朝外)    (中间)          (左边缘,出线方便)
                          └───────────────────────────────────────┘
```

- ESP32 靠**右边缘**（USB 头朝板外，方便插充电宝线）；MAX13487 居中；**A/B/GND 端子在左边缘**（出线到真机方向）。
- 两个模块之间留 3~4 行孔距，走线空间充足。
- **排母方案优先**：把排母焊在洞洞板上，模块插上——模块坏了好换、拆装不烫芯片。

## 3. 接线表（8 根 + 2 短接，照抄面包板现状）

| # | 从（ESP32-C3 SuperMini） | 到（MAX13487 模块） | 说明 |
| --- | --- | --- | --- |
| 1 | `5V` | `VCC` | 模块必须 5V |
| 2 | `5V` | `EN` | **固定高电平**；不得悬空/GND/动态切换 |
| 3 | `G` | `GND` | 共地 |
| 4 | `21`（UART1 TX） | `RXD` | ESP32 发 → 模块收 |
| 5 | `20`（UART1 RX） | `TXD` | 模块 `RO` 输出 → ESP32 收（**直连**，见红线④） |
| 6 | 模块 `A` | 端子 `A` | → 真机 A（**字母对字母**，勿按位置） |
| 7 | 模块 `B` | 端子 `B` | → 真机 B |
| 8 | 模块 `GND` | 端子 `GND` | 共地出线（真机侧 GND） |

- **就这 8 根**。没有别的（LED 是板载 GPIO8 自带；无 DE 脚；3.3 引脚不用）。
- `A/B/GND` 三根走端子；板内 5 根（#1~#5）可用导线飞线或走锡。

## 4. 焊接步骤

1. **先拍照**面包板现状（每个角度，接线对照用）。
2. 排母/端子定位、焊接（先焊固定件，后插模块——**焊接时模块一律不插在排母上**，防烫）。
3. 板内飞线 #1~#5（每焊一根在接线表上打勾）。
4. 端子压/焊 A/B/GND 出线（#6~#8）。
5. **万用表逐根核对**（必做，不核对不通电）：
   - 通断档逐根：接线表 #1~#8 两端应鸣响；
   - **电源短路检查**：`5V`↔`GND` 之间**不得鸣响**（阻值应 >10kΩ）；
   - 相邻引脚间无桥连（尤其 ESP32 的 20/21 相邻）。
6. 全部核对通过 → 插上两个模块 → 上电。

## 5. 上电验证流程（焊接完成后，砚青跑）

| 步骤 | 现象/判据 |
| --- | --- |
| ① USB 上电（充电宝） | LED **慢闪**（WiFi 未连）→ **轻闪**（连上 402FBS） |
| ② 电脑起监听（8888） | 心跳行到达，`poll_ok/poll_err` 正常累计 |
| ③ 485 悬空（A/B 不接真机） | 约 3 轮后 `mode:"3seg"` + `err seg:"S1"`（降级正常 = ESP32↔模块通信 OK） |
| ④ LED **每秒长亮 200ms** | 悬空失败脉冲（语义正确） |
| ⑤ 断电接真机 A/B → 合闸 → 上电 | 数据行 `seg:"1"`、39 字段、raw 78B、`quality:OK` |
| ⑥ 连续采样 ≥5 分钟 | 成功率 100% 基线不回退 |

①~④ 在桌面即可完成（不需要动配电箱）；⑤⑥ 需要断电窗口。
