> ⚠️ **红线**
> ① 模块按**字母**接不按位置。逻辑侧丝印顺序是 **`GND` → `TXD` → `RXD` → `VCC` → `EN`**；总线侧是 **`B` → `A` → `GND`**（GND 在最后）。
> ② `EN` 接**固定 3.3V**，不得悬空 / 接 GND / 动态切换。**不要接 5V**（v1.0 写的是 5V，2026-10-21 更正，见 §7）。
> ③ **所有 GND 共地**（ESP32 / MAX13487 / 端子 / 电源）。
> ④ `RXO`（= 模块 `TXD`）接 `GPIO20` 前**必须先万用表实测空闲电平**，见 §0。
> ⑤ `VCC` 必须 5V，**不得接 3.3V**（MAX13487 是 5V 器件）。
> ⑥ 模块板载已有 `472 / 121 / 472`（4.7k 偏置 / 120Ω 终端 / 4.7k）⇒ **洞洞板上不得再加终端或偏置**。

## 0. 动手前唯一强制前置：实测 RXO 空闲电平

这一项在项目里挂了很久（`02_docs/21` Q-10），一直没做。**不测不许焊**：万一要加分压，等于重焊 GPIO20 那一整路。

| 步骤 | 操作 | 判定 |
| --- | --- | --- |
| 0.1 | 断电。只给模块接 `5V` 与 `GND`（**EN 悬空**），上电 | 模块电源灯亮 |
| 0.2 | 数字万用表直流电压档，黑笔接模块 `GND`，红笔接模块 `TXD` | 读数为空载电平 |
| 0.3a | **3.2–3.4 V** | 3.3V 电平 ⇒ **直连 GPIO20**，按本卡接线 |
| 0.3b | **4.5–5.1 V** | 5V 电平 ⇒ **停**：需 1k 上 / 2k 下分压，复测须落在 2.0–3.3 V，接线图要改 |
| 0.3c | 0 V 或读数跳动 | 模块坏 / EN 未拉高 / 表笔没接触 ⇒ 不得焊 |
| 0.4 | 把读数填进 §8 记录表「RXO 空闲电平」 | — |

> 为什么不能靠"之前直连跑通过"：那是**面包板 + 另一块模块**的实测。换模块、换批次都可能变。而且 GPIO20 绝对最大额定 3.6V，5V 直灌会打穿引脚。

## 2. 布局（横放，元件面朝上）

```
 [5V/2A USB-C]            ┌────────────── 洞洞板 70×90 ──────────────┐
      │                   │                                        │
      ▼                   │  [排母:ESP32-C3]     [排母:MAX13487]    [端子:A B GND]
   ESP32 的 5V/G          │   (靠右,USB朝外)       (居中)            (靠左,出线方便)
                          └────────────────────────────────────────┘
```

- ESP32 靠**右边缘**（USB 头朝板外，方便插电源线）；MAX13487 居中；**A/B/GND 端子在左边缘**（出线朝真机方向）。
- 两模块之间留 **3–4 行孔距**（7.6–10.2 mm）走线。
- SuperMini 两排母**行距 15.24 mm（6 格）**；模块 3 针排相对 5 针排**偏 1 格（居中）**。
- **排母方案优先**：排母焊板上、模块插上去。模块坏了好换，拆装不烫芯片。

> 正式动手前必须先在 **A4 5mm 方格纸上画 1:1 图**并签核，规格见 `05_hardware/洞洞板布局图_2026-10-21.md`。**图上没签字不焊。**

## 3. 接线表（8 根，无短接）

| # | 从（ESP32-C3 SuperMini） | 到（MAX13487 模块丝印） | 线色 | 说明 |
| --- | --- | --- | --- | --- |
| 1 | `5V` | `VCC` | 红 | 模块必须 5V |
| 2 | **`3.3`** | **`EN`** | 蓝 | **固定高电平；v1.1 从 5V 改为 3.3V** |
| 3 | `G` | `GND` | 黑 | 共地（参考地，先焊这条） |
| 4 | `21`（UART1 TX） | `RXD` | 绿 | ESP32 发 → 模块收（**交叉**） |
| 5 | `20`（UART1 RX） | `TXD` | 黄 | 模块 RO 输出 → ESP32 收（**交叉**，先看 §0） |
| 6 | 模块 `A` | 端子 `1` | 橙 | 字母对字母，勿按位置 |
| 7 | 模块 `B` | 端子 `2` | 橙 | — |
| 8 | 模块 `GND` | 端子 `3` | 黑 | 真机侧 GND |

**就这 8 根，没有第 9 根，也没有"2 根短接"。** LED 是板载 GPIO8 自带；MAX13487 **无 DE 脚**；`5V` / `3.3` 各只用一次。

### 3.1 为什么 #4/#5 是交叉的

模块丝印写的是**模块自己的收发方向**，不是芯片脚名：

- 模块 `RXD` = 芯片 `DI`（驱动输入）⇒ 要接 ESP32 的 **TX**（`GPIO21`）
- 模块 `TXD` = 芯片 `RO`（接收输出）⇒ 要接 ESP32 的 **RX**（`GPIO20`）

同名的 `TXD→TXD`、`RXD→RXD` 接法会**双向全断，而模块电源灯照常亮** —— M4 阶段在这上面耗了五天。

## 4. 焊接步骤

1. **拍照**面包板现状（正面 / 背面 / 两个 45°，接线对照用）。
2. **排母定位并焊接**（两根 1×8、一根 1×5、一根 1×3）。先只焊对角两个脚固定，**干插模块校正几何**，确认能顺利插入后再补焊其余脚。
   - ⚠️ **焊接全程模块一律不插在排母上**（防烫、防焊锡飞溅）。
3. **焊端子**（3P 5.08 mm）。端子热容量大，先焊它可以避免后面烫坏细线。
4. **先焊 #3（GND）**：先把参考地建立起来，后面所有测量都以它为基准。
5. 焊 #1（红，5V）、#2（蓝，3.3V→EN）。#2 两端套热缩，因为它紧邻 5V 走线。
6. 焊 #4 / #5（绿 / 黄）。这两根**双绞并远离电源线**，减少串扰。
7. 焊 #6 / #7 / #8（橙 / 橙 / 黑）到端子。
8. 清洗助焊剂、热缩收口、给飞线做应力释放（点一点热熔胶或扎带）。
9. 在每根线两端套/贴 `W1…W8` 标签（后面电检要逐根点名）。
10. **电检（§5），不通过不上电。**

## 6. 上电时序（每步之前都断电、验电）

| 阶段 | 状态 | 判据 |
| --- | --- | --- |
| **S0** | 什么都不插，断电 | M1–M15 全过 |
| **S1** | 只插 ESP32，USB 供电 | 5V 引脚 4.75–5.25 V；3.3 引脚 3.25–3.35 V；**EN 对 GND = 3.25–3.35 V（读到 5 V 立即断电）** |
| **S2** | **断电后**插模块，5V/2A 供电（**不接电脑**） | 模块灯亮、无发热、无异味；测 M16 应 ≈120 Ω |
| **S3** | A/B 悬空（不接真机），电脑起接收端 | 约 3 轮后 `mode:"3seg"` + `err` 行 `seg:"S1"` ⇒ ESP32↔模块通路正常 |
| **S4** | **断电**接真机 A/B（先断电验电） | 数据行 `seg:"1"`、39 字段齐全、`quality:"OK"`、连续 5 min 成功率 100% |

S1–S3 在桌面完成，不用动配电箱。S4 需要断电窗口，按 `06_tests/M5_真机联调操作卡.md` 的安全协议走。
