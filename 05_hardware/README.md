## 1. ⚠️ 两套板子不是同一块，别搞混

这是本目录最容易出错的地方：`carrier/` 和 `pcb/` 是**两个互斥的方案**，不是版本迭代。

| | `carrier/` 载板 | `pcb/` 定制板 |
| --- | --- | --- |
| **本质** | 把**现成模块**插上去 | 把**芯片焊上去** |
| 主控 | ESP32-C3 SuperMini 小板（HW-466AB） | ESP32-C3-**MINI-1** 模组 |
| 485 | 蓝色 MAX13487 模块（RS485 V2.05） | **裸 MAX13487E**（SOIC-8） |
| 装配 | **2.54mm 母座 + 螺钉端子，手焊可做** | 回流焊 / 贴片 |
| 优点 | 模块可插拔、坏了好换、不用买模组 | 体积小、成本低、可量产 |
| 状态 | 布局 + 布线完成，DRC 0 未连接 | 板框/布局/铺铜完成，**布线未完成** |
| 适用 | **现在这个阶段**（验证、答辩、小批量） | 后续量产 |
| 详情 | `carrier/README.md` | `pcb/README.md` |

> 结论：**要动手做板子，先看 `carrier/`**。`pcb/` 目前不是可投板成品。

## 4. 接线与装配

| 文件 | 说明 |
| --- | --- |
| `接线说明.md` | 面包板阶段的接线规范与安全红线 |
| `洞洞板固化操作卡_2026-10-08.md` | 把面包板固化成洞洞板的现场操作卡 |

### 三条最容易致命的接线事实（原文见 `接线说明.md`）

1. **`TXD`/`RXD` 是交叉约定**：`GPIO21` → 模块 `RXD`；`GPIO20` ← 模块 `TXD`。同名对接会双向全断，而模块电源灯仍亮。
2. **总线侧顺序是 `B` / `A` / `GND`**，GND 在最后。旧材料记作 `GND/A/B` 是错的。
3. **EN 接固定高电平**，不悬空、不接 GND、不动态切换。

| 类别 | 是否入库 | 说明 |
