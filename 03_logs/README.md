## 2. 命名约定（后续新增日志请遵守）

```
<阶段>_<场景>_<YYYYMMDD>[_<序号>].log
例：batch3_real_20261008.log / m7_longrun_20261020.log
```

- **`real`** = 接真机的数据（证据级）
- **`serial` / `udp` / `boot`** = 单通道抓取
- **`review_compile`** = 复核用编译输出
- 新日志**不要**再用 `pio3_b/c/d...` 这种无意义后缀。
