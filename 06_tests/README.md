### `m4_accept.py` 的五段档位（按从站收到的请求序号）

| 阶段 | 请求序号 | 从站行为 | 验的是 |
| --- | --- | --- | --- |
| 1 基线 | 1–10 | 正常应答 | 链路可用（若此处全超时，先别往下看，去查接线） |
| 2 静默 | 11–20 | **不应答** | 制造连续 10 次超时 |
| 3 恢复 | 21–30 | 正常应答 | **补测 1**：超时后仍继续轮询 |
| 4 CRC 注入 | 31–35 | 回 CRC **错 1 位**的帧 | **补测 2**：CRC 能被识别且不崩溃 |
| 5 长稳 | 36–N | 正常应答 | **补测 3**：N 次累计（N 默认 1000） |

- **先跑 `60` 冒烟**（约 1 分钟）确认脚本与链路都正常，再跑 `1000`（约 17 分钟）。
- 退出码：`0` = 三项全 PASS，`2` = 有 FAIL，`1` = 串口打不开。
- 运行期间**不要让 ESP32 复位**（固件计数器会归零，账目就对不上；我的脚本自己是独立计数的，不受影响）。
- 原始日志写 `03_logs/M4验收补测_<时间戳>.log`，报告写 `03_logs/M4验收补测_report.txt`（`03_logs` 不入库）。

## 3. ⚠️ 方法学红线（务必遵守）

### 3.1 「短接 A/B 发 abc 看回显」是**无效**的自环测试

- 两线半双工 485 短接 A/B 后差分 `V_AB ≡ 0`，接收器判据是 `|V_AB| > 200mV` → 落在判定窗口**正中间**；
  标准 fail-safe 器件输出不确定、full-fail-safe 器件恒输出高 ⇒ **健康模块也不会回显**。
- **负结果不能证明模块坏。** 本项曾导致一只完好的模块被判"物理损坏"。
- 依据：MaxLinear XR33156 应用笔记、Renesas KB「fail-safe short」、Industrial Monitor Direct / US Converters 知识库。
- 👉 **正确做法：用 `two_port_loopback.py` 做两端口背靠背互测。**

### 3.2 免仪表能力边界

| 待验证的事 | 免仪表 | 工具 |
| --- | --- | --- |
| 485 模块收发是否正常 | ✅ | `two_port_loopback.py` |
| 节点 / 布线是否连通 | ✅ | 用已验证的模块对在同一节点互测 |
| 器件是否在驱动总线 | ✅ | `bus_sniff.py` / `m4_verify.py` |
| MCU 引脚与串口通路 | ✅ | 固件 `RS485_MODE_LOOPBACK_SELFTEST=1` + 短接 GPIO21↔GPIO20 |
| **器件是否通电（VCC 有无 5V）** | ❌ | **必须万用表** |
| 两点之间是否导通 | ⚠️ 只能间接 | 让信号"穿过被测物"走一圈 |

### 3.3 常用判定口径

| 现象 | 结论 |
| --- | --- |
| 485 端口收到 `01 03 00 00 00 02 C4 0B` | ESP32 的请求帧上了总线 ⇒ **发送通路正常** |
| ESP32 打印 `[M4] 解析 OK ... REG: [0]=10 [1]=20` | **双向全通**（M4 通过判据） |
| 双方都是 0 字节 | **双向全断** ⇒ 故障在"共用段"（A/B 总线 / 收发器 / 共地） |
| 收到乱码而非零字节 | 极性反 / 波特率不符 / 偏置不足 —— **注意：零字节 ≠ 极性反** |
| `[M4] 超时 … RX=8 期望 9`（半帧） | **PC 侧 USB 转 485 批量交付抖动**（R-15），非固件/ESP32 缺陷；M5 真机 + 阈值 4~8ms 后应消失。1000 次补测中实测命中 1 次，见 `02_docs/15` §4.1 |

## 4. 前置检查

1. 关掉 Arduino IDE 的**串口监视器**（同一端口不能同时被两个程序打开）。
2. 只允许**一个程序**占用某个 COM 口（如 `m4_slave_rtu.py` 与 Modbus Slave 不能同占）。
3. 端口号每次换 USB 口都会变，先确认：
   ```
   python -c "import serial.tools.list_ports as lp;[print(p.device,'|',p.description,'|',p.hwid) for p in lp.comports()]"
   ```
   已知：**ESP32 = `VID:PID 303A:1001`**；USB 转 485 = CH340 `1A86:7523` / FTDI `0403:6001`。
