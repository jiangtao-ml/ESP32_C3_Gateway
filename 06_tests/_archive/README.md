## 为什么保留而不删除

这两个文件代表的都是**被证伪的做法**。删掉它们，下次有人（或某个 AI）还会再踩一遍同样的坑。
它们是 M4 卡 5 天的物证，属于 `PROGRESS.md` §2b 所说的「排障记录 = 复现依据」。

**但不要在活跃工具链里使用它们。**
