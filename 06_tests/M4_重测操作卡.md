> 1. 本卡第 0 步「A/B 短接自环」**是无效方法** —— 两线半双工 485 短接 A/B 后 `V_AB ≡ 0`，接收器落入 ±200mV 不定区，**健康模块也不会回显**。详见 `02_docs/14_M4排障全过程复盘_2026-10-04.md` §4.1。

## 1. 第 0 步（⚠️ 2026-10-04 更正）：单端口 A/B 自环的做法**作废**

> ### ⚠️ 原做法错在哪
> 「短接 USB 转 485 模块的 A/B，发 `abc` 看回显」**没有判别力**：两线半双工 485 短接 A/B 后差分 `V_AB ≡ 0`，而接收器判据是 `|V_AB| > 200mV` —— 正好落在判定窗口**正中间**，输出不定（标准 fail-safe 器件输出不确定，full-fail-safe 器件恒输出高）→ **健康模块同样不回显**。负结果不能证明模块坏。
> 依据：MaxLinear XR33156 应用笔记、Renesas KB「fail-safe short」、Industrial Monitor Direct / US Converters 知识库。详见 `02_docs/13_M4排障记录_2026-10-04.md` §2。

**正确做法：必须用两个 485 端口背靠背互测**（A↔A、B↔B、GND 共地）。

本项目的 `USB 转 485`（电脑侧）↔ `MAX13487`（ESP32 侧）**本身就是一组合法互测** —— 也就是说，**M4 测试本身就是那个有效测试**，不需要额外的单端口自环。

- [ ] 第 0 步已并入第 4 步（跑 M4）执行，**两侧同时观察**：
      - 电脑侧从站日志是否收到**合法请求帧**（= 去程通）
      - ESP32 串口是否出现 `[M4] 解析 OK`（= 回程通）
- [ ] **若两侧都为 0 字节 → 双向全断 → 故障在共用段（A/B 总线 / 两个模块 / 共地）→ 转 `02_docs/13_M4排障记录_2026-10-04.md` §5 的万用表测量清单**

## 2. 第 1 步：验 GPIO20 是死是活（回环模式，不接 MAX13487）

目的：R-13（GPIO20 可能被 5V 打坏）。**必须在怀疑模块之前先排除它** —— 引脚坏掉的症状和模块损坏完全一样。

1. [ ] **断电**。改 `config.h`：`RS485_MODE_LOOPBACK_SELFTEST` → **`1`**。
2. [ ] 用杜邦线**短接 GPIO21 ↔ GPIO20**（SuperMini 上 USB-C **对侧那一排的末端两个脚**，先认板面丝印）。
3. [ ] **MAX13487 完全不接**（避免 5V 灌进 GPIO20）。
4. [ ] 烧录，开串口监视器 **115200**。跑 **满 1 分钟**。

**判读**

| 现象 | 结论 | 动作 |
| --- | --- | --- |
| 每秒 `[485] 回环 OK TX=8 RX=8 \| 01 03 00 00 00 02 C4 0B`，1 分钟 `统计：成功 60+ / 失败 0 / 超时 0` | ✅ **GPIO20 完好，R-13 解除** | 进第 2 步 |
| `TIMEOUT ... RX=0`（且短接线确认无误、`USB CDC On Boot = Enabled`） | ❌ **GPIO20 输入通路已损坏** | 换脚：`config.h` 的 `RS485_RX_PIN` 改 **GPIO4 / GPIO5 / GPIO10**（避开 strapping 脚 2/8/9 与原生 USB 18/19），同步改 README §6.1 与 CTX 三节；**此时先别往下走** |
| `TIMEOUT ... RX=N`（0<N<8） | 半帧 | 查杜邦线接触；确认 MAX13487 确实没挂在总线上 |

5. [ ] **测完务必把 `RS485_MODE_LOOPBACK_SELFTEST` 改回 `0`**（不改回，第 4 步会按 8 字节判帧、全是"帧长异常"）。

## 3. 第 2 步：实测 RXO 空闲电平 → 决定直连还是分压

**这一步是硬性前置**：测错方向会导致"高电平被判成低"，链路必然不通。

1. [ ] **断电**接线：ESP32 `5V` → 模块 `VCC`；ESP32 `GND` → 模块 `GND`；ESP32 `GPIO21` → 模块与芯片 `DI` 相连的脚（丝印通常 `TXD`）。
2. [ ] 模块的 `RXO` / `RXD` 脚（芯片 `RO` 输出）**先悬空，不接 GPIO20**。
3. [ ] **上电**，用万用表**直流档**量 `RXO` 对 `GND` 的空闲电压：

| 实测 | 结论 | 接法 |
| --- | --- | --- |
| **≈5V** | 电平过高，必须降压 | `RXO —[1kΩ]— 分压节点 —[2kΩ]— GND；分压节点接 GPIO20`（≈3.33V） |
| **≈3.3V** | 直连 | `RXO` **直接**接 GPIO20，**不得加分压**（分压后 ≈2.2V < VIH 2.475V，必然收不到） |
| **≈0V** | 异常 | 先查 EN 是否已接高（未接高时 SHDN# 可能被拉低而关断器件） |

> **严禁**：只串一个 1kΩ 直进 GPIO20（不构成分压，5V 灌进 3.3V 引脚）；**严禁** 2kΩ 接 RXO、1kΩ 接 GND（分压点仅 1.67V）。

4. [ ] **断电**，按上表结果把 `RXO`（或分压节点）接到 `GPIO20`。

## 4. 第 3 步：四必做（接线总核对）

- [ ] **① 分压**：按第 2 步实测结果执行（5V → 1k/2k；3.3V → 直连）
- [ ] **② 共地**：ESP32 `GND`、MAX13487 `GND`、USB 转 485 模块 `GND` → **接到同一点**（星形，不要串成一长串）
- [ ] **③ EN**（已确认 MAX13487）→ **接固定高电平**，首选模块 `VCC`/5V；**不得悬空 / 不得接 GND / 不得动态切换**
- [ ] **④ 逻辑侧两根数据线**（**以信号方向为准，不以丝印名为准**）：
      - ESP32 `GPIO21`（TX）→ 模块与芯片 `DI` 相连的脚（丝印通常 `TXD`）
      - 模块 `RXO`/`RXD`（芯片 `RO`）→（按第 2 步分压或不分压）→ ESP32 `GPIO20`
      - 丝印名在国产模块上两种约定都有：**先按同名对接试；若仍 `RX=0` 或出现 `帧长异常`，断电后只对调这两根再试。**
- [ ] **⑤ 总线 A/B**：MAX13487 的 `A` ↔ USB 转 485 的 `A`，`B` ↔ `B`，极性一致、不交叉；两端接线牢固
- [ ] **⑥ `USB CDC On Boot = Enabled`**（否则 `Serial` 占 GPIO20/21 与 `Serial1` 抢脚）
- [ ] **⑦ 确认未由电脑 USB 给强电侧供电**（真机阶段才涉及；台架阶段不受限）

## 5. 第 4 步：跑 M4

**烧录前必须改的 3 处 `config.h`**

| 参数 | 值 | 理由 |
| --- | --- | --- |
| `RS485_MODE_LOOPBACK_SELFTEST` | **`0`** | 走真实总线模式 |
| `RS485_CHAR_TIMEOUT_MS` | **`20 ~ 30`**（临时） | 电脑端从站经 USB 转 485 会**批量交付**字节，字节间有数毫秒空隙；4ms 会被误判"半帧"，现象是**每秒都超时**、极易误判成模块坏。M5 接真机（纯硬件 UART）后**改回 4ms** |
| `RS485_DE_PIN` | **`-1`**（保持） | MAX13487 无 `DE` 脚，靠 AutoDirection |

**电脑端 Modbus Slave 设置**

| 项 | 值 |
| --- | --- |
| Connection | Serial Port → 选**新模块**的 COM 口 |
| 模式 | RTU，9600 / 8 / N / 1，无流控 |
| Slave ID | **1** |
| 功能 | **03: Read Holding Registers** |
| Address / Quantity | **0** / **2** |
| 数据 | 双击 `0`、`1` 两行填 **10** 与 **20** |
| 状态 | 窗口保持打开且已 `Connect` |

**判定（M4 通过条件）**

- [ ] 每秒一行 `[M4] 解析 OK ADDR=1 FUNC=0x03 DATA=00 0A 00 14`，且 `REG: [0]=10 [1]=20`
- [ ] **连续 ≥60s** 无 `超时` / `CRC 失败` / `帧长异常` / `地址不匹配`
- [ ] 每 100 次打印 `[485] 统计：成功 100 / 失败 0 / 超时 0`

## 6. 失败判读速查

| 现象 | 优先怀疑（按序排查） |
| --- | --- |
| `超时 ... RX=0` | 未共地 → A/B 接反 → EN 未接高（关断） → RXO 未接到 GPIO20 / 分压接错 → **逻辑侧两根数据线接反（断电对调）** |
| `超时 ... RX=N`（0<N<9） | 波特率/帧格式不一致（须 9600 8N1 无校验）→ 半帧（接触不良）→ `RS485_CHAR_TIMEOUT_MS` 还太小 |
| `帧长异常 期望 9 收到 8` + `[诊断] RX 帧 == TX 帧` | 自发自收：接收器被常开，或 `RE#` 被拉低 → 查 EN 接法 |
| `地址不匹配 期望 1 收到 N` | 从站 ID 不是 1，或帧错位 |
| `CRC 失败` | 从站 CRC 字节序不对（应低字节在前）→ 线路噪声 → 空闲差分偏低（偏置不足） |
| 接收到数据但全是乱字节 | 未共地 → RXO 未分压 → 总线偏置/终端异常 |

> 若上电后量得总线空闲差分 `V_A − V_B ≈ 60mV`（而非 ≥200mV），先**停手**报总控：属偏置不足，会表现为"CRC 全败 / 偶发乱字节"，不要反复烧录排障。
