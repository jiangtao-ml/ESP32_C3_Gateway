## 3. 出下一份指令的规矩（`PROGRESS.md` §2b）

1. **一次只推进一个最小可验证目标** —— 不要把 5 件事塞进一份指令。
2. **写清禁区**：哪几行、哪个函数**不许动**（`10` 号就是范例，列了 12 项禁区）。
3. **要求双模式编译**：`SELFTEST=0` 与 `=1` 都要 0 error。
4. **作者 ≠ 验证者**：让 A 写、B 复核，复核指令**明确写"不要改代码，只挑错"**。
5. **不确定的标 `[待确认]`**，**禁止发明协议或寄存器**。
