# ESP32-C3 Gateway

## 1. 项目名称

ESP32-C3 Gateway（ESP32-C3 边缘网关）

## 2. 项目目标

以 ESP32-C3 为主控，构建一个边缘数据网关：向下对接工业现场设备，向上通过
无线网络把采集到的数据转发到上位机 / 云平台，并提供本地调试与运维手段。

阶段性目标拆解（后续阶段逐步实现）：

1. 打通 ESP32-C3 开发环境与最小编译烧录链路。
2. 完成 WiFi 联网与 NTP 对时。
3. 完成 RS-485 物理层驱动。
4. 在 RS-485 之上实现 Modbus RTU 主站/从站协议栈。
5. 完成数据上行（如 MQTT / HTTP）与本地缓存、断线重连。

> 说明：目标章节只描述方向，不代表当前已实现。当前进度见第 4 节。
