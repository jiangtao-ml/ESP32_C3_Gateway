# ESP32-C3 替换树莓派网关项目

## 1. 项目名称

ESP32-C3 替换树莓派网关项目

## 2. 项目目标

### 2.1 项目背景

现有架构使用树莓派（成本 500-800 元）作为中间数据采集网关，节点数量多，导致整体成本过高。

### 2.2 项目目标

使用 ESP32-C3 SuperMini（约 50 元）+ MAX13487 RS-485 模块替换现有树莓派网关，重写架构，当前目标是先在面包板上跑通原型机。

核心动机是降成本：树莓派约 500-800 元，ESP32-C3 SuperMini 约 50 元。

系统数据流：

1. 底层设备：QI 用电数据采集设备（约 300 元），支持 RS-485 通信，Modbus RTU 协议。
2. 中间网关：ESP32-C3 SuperMini + MAX13487 485 模块，负责轮询采集、加时间戳、UDP 上传。
3. 上层接收：电脑上的“网络调试助手”通过 UDP 协议接收数据（内容为“时间戳 + HEX 数据”）。

2. **阶段二：环境搭建与基建** —— 装软件、清点硬件、建目录、查 COM/IP。
3. **阶段三：分模块验证（先软后硬，先模拟后真机）** —— WiFi/NTP/UDP 联通 -> 485 物理回环 -> 电脑模拟 Modbus 从站 -> 接入 QI 真机。
4. **阶段四：系统集成与稳定性测试** —— 非阻塞状态机加固（最小状态机自阶段三 M2 起已在位）、异常处理、2 小时压力测试。
5. **阶段五：项目验收与结项** —— 成本对比、交付物整理、演示准备。

## 6. 关键硬件与安全约束

### 6.1 硬件清单

- 主控：ESP32-C3 SuperMini，3.3V 逻辑，使用 HardwareSerial(1)，RX=GPIO20，TX=GPIO21（主控板 PCB 型号 HW-466AB）
- 扩展底板：HW566 V0.0.1 扩展板（提供 5V、3.3V、锂电池供电接口）。面包板原型阶段（阶段三）暂不使用；直接由电脑 USB 给 ESP32-C3 供电，由 SuperMini 的 5V 引脚给 MAX13487 供电。HW566 留到阶段四/五上锂电池时再启用。
- 通信模块：RS-485 模块（主芯片型号待丝印复核，见下条）。若为 `MAX13487` / `MAX13488`：+5V 供电、AutoDirection 自动方向控制、无需 DE/RE 控制引脚（EN 固定高电平）；若为 `MAX485` / `MAX3485`：EN 即方向控制脚，须由 GPIO 动态切换（固件已内建 `RS485_DE_PIN`，默认 `-1` 不启用）。
- ⚠️ **【待复核·高优先】实物 485 模块主芯片型号**：用户 2026-10-03 口述为 `MAX13487`（与老师说法一致），但购买页为三合一款（`MAX3485` 3.3V 单向 / `MAX485` 5V 单向 / `MAX13487` 5V 双向）、页面渲染图丝印为 `MAX485 ESA` —— 页面图不能代表实物。**M4 接线前必须先读实物 8 脚芯片丝印复核**。若复核为单向芯片，则须增加 DE/RE 方向控制 GPIO 并改造固件。
- EN 引脚（⚠️ 接法随实物芯片型号二选一，先读丝印）：① `MAX13487` / `MAX13488`（5V 双向，芯片无 DE 脚）→ 接**固定高电平**（模块 VCC/5V），不得悬空 / 接 GND / 动态切换（悬空若对应 SHDN# 会关断器件）；② `MAX485` / `MAX3485`（单向，EN 即方向控制脚）→ EN 必须接 GPIO 由固件切换，**严禁固定接高**。详见 `04_ai_prompts/00_context.md` 三.5。固件侧：MAX485 / MAX3485 接法只需把 `01_firmware/esp32c3_gateway/config.h` 的 `RS485_DE_PIN` 改成实际 GPIO 号即启用（默认 `-1` = 不启用）。

### 6.2 ⚠️ 安全约束（必须遵守）

1. ⚠️ 共地：ESP32、485 模块（MAX13487 或 MAX485 / MAX3485）、USB 转 485 模块、电源，所有 GND 必须连在一起。
2. ⚠️ 电平转换（极其重要，口径与 `04_ai_prompts/00_context.md` 三.2 完全一致）：485 模块的 RXO 空闲电平必须先万用表实测（Q-10）。① 实测为 5V → 绝对不能直接连 ESP32 的 RX (GPIO20)，必须 1kΩ 接 RXO、2kΩ 接 GND，交点接 GPIO20（约 3.33V）；严禁 2k 接 RXO、1k 接 GND（仅 1.67V，ESP32 无法识别高电平）。② 实测为 3.3V → 直连 GPIO20，**不要分压**（分压后约 2.2V，低于 ESP32-C3 的 VIH ≈ 2.475V，会收成乱码）。**未实测前一律按 5V 处理（必须分压），严禁直连。**（模块侧该脚术语统一为 RXO；部分手册记作 RO / RXD，同一引脚。）
3. 供电：MAX13487 必须接 5V，ESP32-C3 接 3.3V（⚠️ 三合一款中的 MAX3485 变体为 3.3V；实物型号未经丝印复核前，不要盲目按 5V 接线）。
4. 总线：商品页仅注明「具有 120 欧匹配电阻」；4.7kΩ 偏置电阻未经实物核实，须 M3 实测终端/偏置并联数量后回写。
