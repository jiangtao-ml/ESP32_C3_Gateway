## 2. 系统链路

```
STB3-125 电表 ──RS-485 (9600 8N1 / Modbus RTU)──►  ESP32-C3 SuperMini + MAX13487
                                                              │  WiFi
                                                              ▼
                                              UDP:8888 JSON ──►  电脑（Ubuntu）→ SQLite
```

三条设计口径（**别"优化"掉**）：

- **上行 = JSON**：数据行 / 心跳行 `type:"hb"` / 失败行 `type:"err"`；带 `seq`、`dev`、`quality`、`invalid`、`raw`（HEX）
- **轮询 = `0x04` 读输入寄存器**，运行时自适应：启动默认**一帧读全 39 寄存器**（83 B），从未成功且连续 3 轮失败才降级 3 段（37/37/19 B）
- **固件只搬运原始值，不做工程量换算** —— 换算放 PC/服务端 ⇒ 公式可演进、`raw_hex` 可重放

## 5. 三条最致命的红线（都踩过，别再踩）

### ① 485 模块的 `TXD` / `RXD` 是**交叉**约定

模块丝印写的是**模块自身**的收发方向：模块 `TXD` = 芯片 `RO`（收），模块 `RXD` = 芯片 `DI`（发）。

- ✅ 正确：`GPIO21`(ESP32 TX) → 模块 `RXD`；`GPIO20`(ESP32 RX) ← 模块 `TXD`
- ❌ 同名对接 ⇒ **双向全断，而模块电源灯仍亮** —— 这正是 M4 卡五天的真凶
- 复盘：`02_docs/14_M4排障全过程复盘_2026-10-04.md`

### ② 总线侧顺序是 `B` / `A` / `GND`（GND 在最后）

按**字母**接，不按位置接。旧材料记作 `GND/A/B` 是错的。

### ③ 真机在**带电配电箱**里 —— 开箱前断电 + 验电

- 疑似三相 380V ⇒ **必须断全三相**；**无万用表不许开箱**
- **判据：看 485 另一头有没有市电** —— 有市电 ⇒ **充电宝供电 + 拔 USB**
  （否则经 USB 地 + 485 共模可烧电脑主板）
- ⚠️「装的时候断电了」≠「此后一直安全」⇒ **每次改接线前都要再断一次**

> 其余接线事实（EN 接 **3.3V**、`RXO` **直连 GPIO20 不分压**、GND 共地、5V/3.3V 双供电）
> 见 `05_hardware/接线说明.md` 与 `04_ai_prompts/00_context.md` 三.2–三.5。
