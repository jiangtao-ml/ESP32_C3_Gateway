# ESP32-C3 替换树莓派网关项目

## 1. 项目名称

ESP32-C3 替换树莓派网关项目

## 2. 项目目标

### 2.1 项目背景

现有架构使用树莓派（成本 500-800 元）作为中间数据采集网关，节点数量多，导致整体成本过高。

### 2.2 项目目标

使用 ESP32-C3 SuperMini（约 50 元）+ MAX13487 RS-485 模块替换现有树莓派网关，重写架构，当前目标是先在面包板上跑通原型机。

核心动机是降成本：树莓派约 500-800 元，ESP32-C3 SuperMini 约 50 元。

系统数据流：

1. 底层设备：QI 用电数据采集设备（约 300 元），支持 RS-485 通信，Modbus RTU 协议。
2. 中间网关：ESP32-C3 SuperMini + MAX13487 485 模块，负责轮询采集、加时间戳、UDP 上传。
3. 上层接收：电脑上的“网络调试助手”通过 UDP 协议接收数据（内容为“时间戳 + HEX 数据”）。

1. **阶段一：项目立项与规划（文档先行）** —— 编写任务书、制定里程碑。
2. **阶段二：环境搭建与基建** —— 装软件、清点硬件、建目录、查 COM/IP。
3. **阶段三：分模块验证（先软后硬，先模拟后真机）** —— WiFi/NTP/UDP 联通 -> 485 物理回环 -> 电脑模拟 Modbus 从站 -> 接入 QI 真机。
4. **阶段四：系统集成与稳定性测试** —— 非阻塞状态机加固（最小状态机自阶段三 M2 起已在位）、异常处理、2 小时压力测试。
5. **阶段五：项目验收与结项** —— 成本对比、交付物整理、演示准备。

## 6. 关键硬件与安全约束

### 6.1 硬件清单

- 主控：ESP32-C3 SuperMini，3.3V 逻辑，使用 HardwareSerial(1)，RX=GPIO20，TX=GPIO21（主控板 PCB 型号 HW-466AB）
- 扩展底板：HW566 V0.0.1 扩展板（提供 5V、3.3V、锂电池供电接口）。面包板原型阶段（阶段三）暂不使用；直接由电脑 USB 给 ESP32-C3 供电，由 SuperMini 的 5V 引脚给 MAX13487 供电。HW566 留到阶段四/五上锂电池时再启用。
- 通信模块：MAX13487 RS-485 模块，+5V 供电，AutoDirection 自动方向控制，无需 DE/RE 控制引脚。
- EN 引脚：含义待 M1 实测确认（MAX13487 模块丝印为 EN，可能对应 RE# 或 DE，含义不同接法不同）。未确认前保持断开——既不接 3.3V，也不接 GND，也不接线，待 M1 实测后再按结论接入。

### 6.2 ⚠️ 安全约束（必须遵守）

1. ⚠️ 共地：ESP32、MAX13487、USB 转 485 模块、电源，所有 GND 必须连在一起。
2. ⚠️ 电平转换（极其重要）：MAX13487 的 RXO 输出为 5V 电平，绝对不能直接连 ESP32 的 RX (GPIO20)，必须加电阻分压。正确分压：1kΩ 接 RXO，2kΩ 接 GND，交点接 GPIO20（电压约 3.33V）。严禁使用 2k 接 RXO、1k 接 GND（电压仅 1.67V，ESP32 无法识别高电平）。（模块侧该脚术语统一为 RXO；部分手册记作 RO / RXD，同一引脚。）
3. 供电：MAX13487 必须接 5V，ESP32-C3 接 3.3V。
4. 总线：MAX13487 模块自带 4.7kΩ 偏置电阻和 120Ω 终端电阻。

### 6.3 通信参数

- 485：9600，8N1，Modbus RTU

### 6.4 网络

- 电脑 IPv4：192.168.1.117（电脑侧频段未实测，以 M1 实测为准；频段差异本身不是网段不一致的判据。注意 ESP32 仅支持 2.4GHz）
- NTP：ntp.aliyun.com，东八区（UTC+8）
